# 通过jd-gui反编译

[java decompile](http://java-decompiler.github.io/)

下载后启动，加载文件，并去勾选如下配置，然后save all生成zip包

![image-20221213222229963](.\images\image-20221213222229963.png)

# 创建工程结构

此时生成的源码并不是spring-boot的工程结构，可以在`META-INF`找到工程的pom文件，并在官网根据pom文件创建工程模板。

[模板生成站](https://start.spring.io/)

spring-boot工程结构生成后，将源码移入工程对应的源码文件夹

# 启动和调试

之后执行如下命令构建工程

```bash
mvn clean package
```

启动调试

```bash
mvn spring-boot:run -Dspring-boot.run.jvmArguments="-Xdebug -Xrunjdwp:server=y,transport=dt_socket,address=8000,suspend=n"
```

之后vscode上绑定端口进行调试即可
