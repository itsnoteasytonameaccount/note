# 整数拆分

计算整数拆分方法的个数，其中1+3，3+1 视为同一种拆分，因此需要注意顺序。

最蠢的方法，也是我用的方法，不用动脑子的递归：

```c++
// 这种做法只是简单地从要拆分的数中逐个减去数值直到为0或1
// 有非常多重复的计算，举个例子10 = 7 + ...和10 = 4 + 3 + ...的省略号后面部分计算过程其实是一样的
int divide(int n, int m)
{
    int count = 1;
    for(int i = m > n ? n : m; i > 1; i--)
    {
        count += divide(n - i, i);
    }
    return count;
}
```

运行发现超时了，不合题目要求，参考了别人的几种思路

第一种也是递归，不过不是一个个减去，而是计数减去
把数字看作$x_1 * 1 + x_2 * 2 + .... + x_n * n$


```c++
// 这种做法没验证正确性，并且效率也不高
int divide(int remain, int start = 1)
{
    if (remain == 0)
    {
        return 1;
    }
    int count = 0;
    for(int i = 0; i <= floor(n / start); i++)
    {
        count += divide(remain - i * start, start + 1);
    }
    return count;
}
```

第二种方式是采用动态规划

思路如下

对于n的拆分方式定义函数$f(n, m)$代表拆分数，其中n代表需要拆分的数字，m代表拆分出来的式子中最大的数字。可以为$f(n, m)$建立递推式：
$$
\begin{cases}
f(0, 0) = 1\\
f(n, m) = f(n, n)&m,n \in N,&m > n \geq 0\\
f(n, m) = f(n - m, m) + f(n, m - 1)&m,n \in N,&0 <m < n
\end{cases}
$$

所以动态规划代码如下

```c++
int divide(int n)
{
    int **nums = new int[n + 1][n + 1];
    nums[0][0] = 1;
    for (int i = 1; i <= n; i++)
    {
        nums[i][0] = 1;
        for (int j = 1; j <= i; j++)
        {
            nums[i][j] = nums[i - j][min(i - j, j)] + nums[i][j - 1];
        }
    }
    return nums[n][n];
}
```

第三种在第二种的基础上对使用的空间优化了一下，先求$f(1,1), f(2,1)....f(n,1)$再求$f(2,2), f(3,2)...f(n,2)$如此一直求到$f(n,n)$
```c++
int divide(int n)
{
    int *nums = new int[n + 1];
    nums[0] = 1;
    for (int i = 1; i <= n; i++)
    {
        for (int j = i; j <= n; j++)
        {
            // 求f(j, i),i <= j的值时，此时nums[j - i]里正好存的是f(j - i, min(j - i, j))的值，而nums[j]里正好存的是上一次循环得到的f(j, i - 1)的值
            nums[j] = nums[j - i] + nums[j]; 
        }
    }
    return nums[n];
}
```

# 最大公约数

求组合数 C(2n, 1), C(2n, 3), C(2n, 5) ... C(2n, 2n - 1)的最大公约数

这道题考的是数学，代码只需要些一两行

第一步：证最大公约数必是 2 的指数幂形式

用二项式展开

$(1 + 1) ^ {2n} = C_{2n}^0 + C_{2n}^1 + C_{2n}^2 + ... + C_{2n}^{2n} = 2^{2n}$

$(1 - 1) ^ {2n} = C_{2n}^0 - C_{2n}^1 + C_{2n}^2 + ... - C_{2n}^{2n - 1} + C_{2n}^{2n} = 0^{2n}$

联立上式有

$C_{2n}^1+C_{2n}^3+...+C_{2n}^{2n-1} = 2^{2n - 1}$

若上述组合数存在最大公约数 a 那么$2^{2n - 1}$一定可以被 a 整除，显然 a 是 2 的指数幂形式或者 1(2 的 0 次方)

因此上述所有二项式都可以化为$k2^x$的形式。

可设$C_{2n}^1 = 2n = k_12^{x_1}, \forall 奇数m，有 C_{2n}^m = 2n * \frac{(2n - 1)(2n - 2)...(2n - m + 1)}{m!} = k_12^{x_1} * \frac{C_{2n-1}^{m - 1}}{m}$

已知 m 为奇数，$C_{2n}^m$为整数，显然$\frac{k_1C_{2n-1}^{m - 1}}{m}$为整数,所以当 m 为奇数时$\forall C_{2n}^{m}$都以及他们的和至少可被$2^{x_1}$整除，因此最大公因数取绝于$C_{2n}^1$的值。

即求$2^{x_1}$部分的值,可以用位运算来求

可以利用补码的特性，int 类型负值为正值的反码加 1
举例来说，对二进制为 10101010000 的整数来说补码正好是 01010110000，两者按位与得到的结果正好就是这个数字的$2^{x_1}$部分的值 00000010000

最后得到结论，编程的代码很简单

```c++
int main()
{
    int n;
    cin >> n;
    n = 2 * n;
    count << (n & -n) << endl;
}
```
