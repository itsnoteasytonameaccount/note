# 前言

有一个叫kaillerasrv的简单程序需要在后台跑，用`&`在后台跑起来，在shell关闭后就会被杀了。
加`nohup`也不行，一段时间过后就被杀掉了，还是必须将程序做成服务，记录步骤。

<!-- more -->

# 实现

```bash
# 可执行文件名太长，链接一下
ln -s /path/to/kaillerasrv /usr/bin/kail
# 首先在系统里找示例文件，减少工作量
find / -name nginx.service
# 其次复制文件内容，cp或其他什么的都可以
cat /usr/lib/systemd/system/nginx.service>/usr/lib/systemd/system/kail.service
```

之后打开文件，按照[参考](#参考)中给的链接修改配置

```bash
[Unit]
Description=kail
# After=network.target remote-fs.target nss-lookup.target

[Service]
# Type=forking
Type=simple
PIDFile=/run/kail.pid
# Nginx will fail to start if /run/nginx.pid already exists but has the wrong
# SELinux context. This might happen when running `nginx -t` from the cmdline.
# https://bugzilla.redhat.com/show_bug.cgi?id=1268621
ExecStartPre=/usr/bin/rm -f /run/kail.pid
# ExecStartPre=/usr/sbin/nginx -t
ExecStart=/usr/bin/kail
ExecReload=/bin/kill -s HUP $MAINPID
KillSignal=SIGQUIT
TimeoutStopSec=5
KillMode=process
PrivateTmp=true

[Install]
# WantedBy=multi-user.target
```

最后执行`systemctl start kail`即可。

`journalctl -xe` 查看启动日志
