# 概念
## 编址方式
分段，一段即指一块内存区域。
段地址指的是：对应一块内存区域起始位置。
段内偏移地址指：相对段地址偏移的字节数
## 寻址方式
1.  立即寻址
    操作数即为要操作的数据时。
    ```asm
    mov 目的操作数,100
    ```
2.  寄存器寻址
    要操作的数据存在寄存器中，操作数为寄存器名
    ```asm
    mov 目的操作数,ax
    ```
3.  直接寻址
    操作数为要操作数据的地址，或变量名
    ```asm
    mov 目的操作数,value
    ```
4.  寄存器间接寻址
    要操作的数据地址存在寄存器中，操作数形式为中括号内加上寄存器名
    ```asm
    mov 目的操作数,[bx]
    ```
5.  寄存器相对寻址
    寄存器内的地址加上偏移量为要操作数据的段内偏移地址，操作数形式如下
    ```asm
    mov 目的操作数,[cx+n]
    ```
6.  基址变址寻址
    通过两个寄存器的内容获取要操作的数据的地址
    ```asm
    mov 目的操作数,[ax+bx]
    ```
7.  相对基址变址寻址
    5，6混合使用
    ```asm
    mov 目的操作数,[ax+bx+6]
    ```
## 基本常用指令
1.  mov a,b
    将b内容复制到a中,a不可为数字，可为寄存器等，要注意a,b数据形式限制
2.  push/pop a
    a的内容压栈，或弹栈入a,栈的概念请另自行查找
3.  lea a,b
    b的段内偏移地址存入a中
4.  xchg a,b
    交换a,b内容，a,b都不可为数字
5.  and  a,b
    a,b按位与结果存入a,cf,of设为0,af无定义
6.  or   a,b
    a,b按位或结果存入a,对标志位影响同5
7.  xor  a,b
    a,b按位异或结果存入a,对标志位影响同5
8.  not  a
    a按位取反，结果存入a
9.  shl/shr  a,n
    a各位左/右移n位,空出的位补0,当最高位改变时of=1,否则为0,对其他位无影响（注意无影响和未定义区别，未定义指对原有值有影响但结果完全随机）
10. sal/sar  a,n
    a各位左/右移n位,移出的位依次存入cf,空出的位若为高位补上原有值，低位补上0,标志位影响同9
11. rol/ror  a,n
    a各位左/右移n位,移出的位依次补至空出的位,对标志位影响同9
12. add/sub  a,b
    a加/减b结果存入a,加法时进位cf=1,减法a&lt;b则cf=1,同符号相加结果符号改变则of=1，异号相减结果符号与b相同则of=1，减法时结果为0则zf=1
13. adc/sbb  a,b
    加法带进位，减法有借位，cf为进位或借位标记，加法时要加cf,减法时减cf，其余同12
14. inc a
    a自增一
15. cmp a, b
    a,b相减不存结果，标志位影响同sub
16. jmp a
    无条件转移至代码段的a位置
17. jz/jnz a
    条件转移至代码段的a位置(jump if zf equals/not equals 0),其他条件转移指令自行查找
## 子程序
直接上例子
```asm
; ...
call func  ;调用,此时ip,cs内容入栈
; ...
func:
     ; ....
     ret   ;返回，此时原来存的ip,cs出栈
```
## 常用中断程序,21h号中断
|中断号|作用|
|:-:|:-:|
|01h|输入一个字符，结果存入dl|
|02h|从dl显示一个字符|
|09h|输出ds:[dx]为起始地址，以'$'结束的字符串|
|0ah|输入以回车结束的字符串,结果存入ds:[dx]|
|0ch|清空键盘输入缓存|
用法
```asm
;输出字符0
mov ah,02h
mov dl,30h    ;字符0的ascii码
int 21h
```
## 数据
db(byte)/dw(word)/dd(double)/dq(quad) 分别用于定义:字节/字长/双字长/四字长数据，长度分别为1/2/4/8字节，可在数据段代码段堆栈段使用
dup:定义重复数据，使用方法
```asm
db 10 dup(?)  ;定义10字节空闲内存
```
?占位代表数据未定义
